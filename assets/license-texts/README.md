# Standard license texts

These unmodified texts come from the SPDX License List data (CC0-1.0), pinned
in `rust-notices.lock.json`. They supplement explicit licence declarations in
published crates that omit a standalone text. They are not represented as
original upstream copyright notices. Original source declarations and authors
are retained alongside them; placeholders in a standard text are not assertions
about a package's copyright ownership or dates.

Source: https://github.com/spdx/license-list-data/tree/8a04f0303d95c4f932210b118588c662665bd383
